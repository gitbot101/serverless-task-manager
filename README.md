# Serverless Task Manager

## Project Overview

Serverless Task Manager is a full-stack web application designed to help users organize projects, manage tasks, track progress, and store supporting documents.

The application will be developed as a hands-on portfolio project.

## Objectives

- Develop a responsive web application using Angular.
- Implement backend business logic using Node.js.
- Build RESTful APIs using Amazon API Gateway and AWS Lambda.
- Store application data in Amazon DynamoDB.
- Manage documents using Amazon S3.
- Implement authentication and authorization.
- Add automated testing and deployment workflows.
- Document architectural decisions and Agile delivery practices.

## Planned Technology Stack

| Component | Technology |
|---|---|
| Front end | Angular |
| Backend | Node.js and TypeScript |
| API | Amazon API Gateway |
| Compute | AWS Lambda |
| Database | Amazon DynamoDB |
| File storage | Amazon S3 |
| Authentication | Amazon Cognito |
| Monitoring | Amazon CloudWatch |
| Infrastructure as code | AWS SAM |
| Version control | Git and GitHub |
| CI/CD | GitHub Actions |

## Initial Features

1. Create and manage projects.
2. Create and update tasks.
3. Track task status and priority.
4. View project progress.
5. Upload and retrieve supporting documents.
6. Secure application access.
